# NBPI: Noise-Based Processor Interpreter

A long-term project exploring how a processor can predict and tame
its own physical noise, from a custom 8-bit CPU and emulator
to an FPGA implementation and, eventually, real silicon.

## Status
Early stage (October 2026). I am learning the fundamentals:
programming, Linux, Git and digital logic.

## Roadmap
-  Custom 8-bit instruction set and emulator (Python)
-  Assembler
-  CPU in Verilog running on an FPGA
-  Tests with cocotb
-  First chip via Tiny Tapeout
